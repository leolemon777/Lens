# 屏迹 ScreenTrace

屏迹是一款本地优先、开源、AI 原生的截图与录屏工作台：一按即捕捉，停下即成品，之后永远找得到。

当前仓库是 macOS 原生纵向切片，用来验证从捕获、开放项目包、事件轨到自动成片的完整技术链路；它还不是功能完整的 Alpha。

## 已经跑通

- `Fn + Control`：直接进入快速区域截图；
- `Fn + Space`：打开原生“迹光玻璃”操作中心，录制时切换为控制条；
- 区域、独立窗口和当前显示器截图路径；窗口模式支持真实层级悬停高亮；
- PNG 写入、剪贴板、Quick Access 与贴图窗口；
- 选区 OCR：本地 Apple Vision 识别、文字立即复制，并保留 `analysis/ocr.json`；
- Quick Access 对象化标注：矩形、椭圆、箭头、文字、模糊、像素化、颜色、选择/移动/缩放/删除及撤销/重做；
- 标注计划与 `previews/annotated.png` 分离保存，完成后立即复制，原图不改写；
- 原生屏迹库：按时间浏览截图与录屏，支持标题/OCR 本地搜索、类型筛选、打开、复制、标注和 Finder 定位；
- ScreenCaptureKit 区域、独立窗口、当前显示器 60 FPS H.264 原始录屏与系统声音；
- 录屏菜单可独立开关系统声音、麦克风与摄像头；讲解声写入 `raw/microphone.caf`，人像写入 `raw/camera.mov`，均不混进屏幕 MP4；
- 录制控制条支持真实暂停/继续：每段屏幕、系统声、麦克风、摄像头和事件数据先独立安全写盘，停止时无重编码合并，暂停时间不会进入成片时间轴；
- 录制控制条实时显示系统声与麦克风电平；停止后可将独立旁白自动混入预览，并在检测到讲话时平滑压低系统声；
- 录屏项目保留来源模式、显示器/窗口 ID、选区、窗口标题与应用名；窗口移动或缩放时动态校正指针坐标；
- 独立的指针、点击 JSONL 事件轨和中断恢复状态；
- 自动运镜、光标平滑/替换、点击反馈、背景、圆角、阴影与人像画中画的非破坏性编辑计划；
- 自动预览可合成圆形/圆角矩形摄像头人像，支持四角定位、镜像、边距与阴影并保留系统声音；摄像头轨损坏时自动退回屏幕预览；
- 自动导出可分享 MP4 预览，失败时仍保留原始录制；
- 开放 `.screentrace` 项目包；
- 原生设置与权限中心，覆盖屏幕、麦克风、摄像头和辅助功能；
- 93 项单元、捕获几何、独立音轨、分片归档/合并、画中画、旁白检测/自动压低、音频混合、项目兼容、索引、搜索、渲染、UI 快照与媒体集成测试。

## 尚未完成

- 多窗口截图、长截图、编号/高亮等高级标注和完整贴图交互；
- 可交互摄像头布局与自动避让、长时录制与麦克风/摄像头/系统流异常中断真机验证；
- 可交互的统一视频编辑器、字幕/转写、标签与 AI 整理；
- 签名公证、安装器、自动更新和 Windows 适配。

## 开发

```bash
swift test
bash Scripts/build-app.sh
open Build/ScreenTrace.app
```

首次真实截图或录屏时，需要在“系统设置 → 隐私与安全性 → 屏幕与系统音频录制”中授权 ScreenTrace。自动化工具无法代替用户授予该系统隐私权限；物理 `Fn` 组合键也需要手动验收。
