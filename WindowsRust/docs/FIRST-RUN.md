# 第一次运行

此说明只适用于已在 Windows 编译生成的 Lens.exe。源码压缩包本身不含 EXE。

1. 保留 `Lens.exe` 和旁边的 `tools` 文件夹在同一目录；系统需有 WebView2 Runtime。
2. 启动 Lens，选择显示器或窗口；选“区域”时点击“框选区域”。
3. 首先使用 30 FPS，录 10 秒无声视频，停止后在素材库播放，确认方向、尺寸与颜色。
4. 再分别测试系统声、麦克风，最后测试同时开启与暂停/继续。默认声音开关关闭。
5. 开始重要录制前完成 `docs/ACCEPTANCE.md` 真机检查。

项目存放在用户“视频”目录的 `Lens-Windows` 文件夹。成片是 `.lens/previews/preview.mp4`，截图是 `.lens/raw/screenshot.png`。

没有 FFmpeg 时可无声录制单段视频、截图；声音合成和分段暂停不可用。按钮会相应禁用。

录制过程中，关闭窗口会被阻止；应先按“停止保存”，等待保存结束。强退无法保证活动 MP4 恢复，完整保留项目比单独复制成片更有利于排查。

热键：Ctrl+Shift+F9 暂停/继续，Ctrl+Shift+F10 停止保存。与其他软件冲突时请使用应用按钮。
