# Lens G0 基准与发布阻断清单

状态：Active。此文档落实《Lens 1.0：顶级品质产品 SPEC PLAN》的 G0 交付，不替代 G1–G6 的真机退出条件。

## 1. 固定范围

- 1.0 仅发布 macOS；Windows 捕获迁移、跨平台 UI、团队云空间和重型 NLE 不进入当前发布阻断链。
- 两个黄金闭环保持为“快速截图”和“演示录屏”；新增需求必须明确改善其中至少一个闭环。
- 自动效果始终写入非破坏 edit-plan；raw、原始事件和独立媒体轨不可被覆盖。
- 捕获链不能等待 OCR、转写、整理、自动预览或网络服务。
- 不要求用户修改触控板、输入法或系统默认偏好才能完成主路径。

## 2. 固定基准场景

`Config/G0BaselineScenarios.json` 固定 30 条版本化场景，覆盖：

| 范围 | 场景 ID | 数量 |
|---|---|---:|
| 区域/窗口/多窗口/显示器截图、剪贴板、Quick Access、标注与视觉 | ST-G0-001…012 | 12 |
| Safari、Chromium、原生 App、动态内容、失败与上限长截图 | ST-G0-013…018 | 6 |
| 来源选择、四轨录屏、浮标、暂停、长时和故障恢复 | ST-G0-019…028 | 10 |
| 自动草稿、光标、编辑、导出、无障碍与安装 | ST-G0-029…030 | 2 |

每条场景记录发布闸门、证据等级、自动化程度、操作步骤和预期结果。`G0BaselineScenarioTests` 会拒绝缺失、重复、少于 30 条、步骤不完整或带私有绝对路径的清单。

## 3. 自动基线入口

运行：

```bash
bash Scripts/run-g0-baseline.sh
```

命令顺序执行：

1. 全量 Swift 测试；
2. warnings-as-errors Release 构建；
3. App Bundle 重建与严格签名校验；
4. 公开源码隐私与制品审计；
5. 本地截图性能白名单数据聚合。

输出位于 `Build/Quality/`：

- `g0-baseline-latest.json`：测试数、构建、硬件、系统、显示器、Git 身份和工作区状态；
- `capture-performance-latest.json`：遮罩准备、吸附目标和拖拽更新的样本数、P50、P95 与最大值。

性能报告只写聚合耗时，不写媒体、路径、窗口标题、文本、坐标或原始事件。少于 100 个样本会明确标记 `insufficient`，不得用于 P95 发布宣传。
