# Windows UI 试用第 1 版

这是用于实际试用和 UI 反馈的内部版本，产品版本号仍为 0.1.0。Windows 使用 Tauri 2 + Rust，界面为 React + TypeScript。Mac 版仍是 SwiftUI / AppKit。

## 打开

交付目录：`Build/Releases/Windows/UI-Review-01/Lens-0.1.0-x64/app`。

- 直接运行 `Lens.exe`，保留同目录的 dist、lens-worker、ffmpeg、ffprobe 文件。
- 或运行 `Lens_0.1.0_x64-setup.exe` 安装。请先退出正在运行的旧 Lens，避免快捷键被旧进程占用。
- 启动后显示操作中心。关闭操作中心后，使用 Ctrl+Alt+2 再次打开；托盘菜单可以退出程序。

## 建议试用顺序

1. **操作中心**：检查文字是否清晰、尺寸是否舒适；展开截图菜单与录屏设置，按 Esc 返回。数字键 1 截图、2 录屏设置、3 最近素材 OCR、4 长截图、5 贴图。
2. **截图**：Ctrl+Alt+1，拖出选区。检查剪贴板粘贴、保存、Quick Access；再试“截图 → 窗口截图”。
3. **标注**：打开 Lens 库，选择刚刚的截图，检查工具、预览和导出。使用测试素材验证，不要先拿重要素材做删除试验。
4. **录屏**：点击录屏，确认系统声、麦克风和摄像头设置；先试倒计时取消，再录制 10 秒、暂停、继续、停止。检查视频可播放、声音与导出。
5. **UI 反馈**：指出具体界面、操作步骤、预期与实际效果；对照 Mac 同一界面更容易精确调整。重点看密度、间距、字号、反馈速度与弹窗位置。

## 本轮变化

- 启动直接显示操作中心；紧凑窗口按内容调整高度，展开内容可滚动。
- 按 Mac 操作中心保留截图、录屏、更多和最近记录的层次。
- 修复浅色面板继承白字的问题；采用清晰的银白表面作为 Windows 材质降级。
- 录屏先配置再开始，提供三秒倒计时及取消入口。
- 增加 Esc、数字键和可见键盘焦点；打开素材库时收起操作中心。
- 修复本地前端缺失 Rust 命令权限的问题。
- 将创建捕获结果窗口、录制条和贴图的命令移出 UI 线程，修复 Windows WebView2 同步创建窗口的死锁。
- 视频预览使用 Tauri 的资源 URL 转换，避免手工拼接带中文或空格的文件路径。

## 仍待对齐

本轮实测：记事本窗口截图成功落盘，Quick Access 正常显示并打开素材库，截图在编辑器中可见；数字键 2 打开录制设置，设备设置与窗口选择器可展开。Release / NSIS 构建成功，前端类型检查和两个回归检查通过，交付清单 9 个文件 SHA-256 一致。最终交付目录中的 Lens.exe 已启动，并确认读取该目录自己的 dist。此次未完成真实录屏、暂停继续、音视频导出及安装器安装后的全流程复测。

本轮不是 Mac 1:1 最终验收。原生玻璃材质、完整深色主题、Quick Access 动作完整度、素材库与编辑器视觉细节还需迭代。字幕精细时间编辑、视频标注、光标效果、自由画中画等 Mac 功能尚未全部对齐；离线转写仍依赖本地识别工具。多显示器、不同缩放、长时间录制和真实设备组合需要继续试测。

实现依据：仓库 `docs/Lens-Glass-UI规范.md`、Mac `ActionCenterView.swift`，以及 Tauri 官方 [权限说明](https://v2.tauri.app/security/permissions/)。窗口死锁依据为本地 Tauri 2.11.5 `WebviewWindowBuilder` API 注释，并通过实际 Windows 操作复核。
