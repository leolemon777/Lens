## 执行规则

- 按“源码实现 → 自动验证 → 真机操作 → 交付证据”推进；有按钮、有文件或能编译不等于完成。
- 每项分别记录功能、视觉、媒体结果和异常恢复状态。不能用占位结果或静默回退当成功。

- 阶段完成后产出可运行构建及记录；完整 Windows 1.0 需全部阶段验收，首批构建不标记为 1.0 完成。
