# Lens Windows 内测使用指南

当前 Windows 产品入口是 `Desktop/`（Tauri 2 + React + 进程内 Rust）。`Windows/` 旧 WinForms 工程已删除。

## 开发机启动

```powershell
pwsh Scripts/windows/run-lens.ps1
```

或先构建再启动：

```powershell
pwsh Scripts/windows/build.ps1 -Configuration Release
pwsh Scripts/windows/run.ps1 -Configuration Release -DataRoot E:\Lens
```

快捷键：`Ctrl+Alt+1` 区域截图，`Ctrl+Alt+2` 打开操作中心或录制条。截图写入 `.lens` 包、复制到剪贴板，并出现在 Lens 库。录制可暂停/继续，停止后可在预览区播放并导出。默认库目录为 `E:\Lens`。

操作中心还提供：窗口截图、长截图、标注、OCR、贴图、库搜索与删除。

未签名安装器（若本次打包生成了 NSIS）：

`Desktop\src-tauri\target\release\bundle\nsis\`

## 获取并验证制品

```powershell
pwsh Scripts/windows/package.ps1 -Channel internal -Architecture x64 -Version 0.1.15
pwsh Scripts/windows/verify-release.ps1 `
  -ManifestPath Build/Releases/Windows/Lens-0.1.15-x64/release.json `
  -Mode Development
```

运行目录为 `Build/Releases/Windows/Lens-<version>-x64/app/`，其中主程序为 `Lens.exe`。当前制品未签名，不能当作公开安装器分发。

## 内部安装、升级与回滚烟测

```powershell
pwsh Scripts/windows/install.ps1 -Action Install `
  -PackageRoot Build/Releases/Windows/Lens-0.1.15-x64 `
  -InstallRoot E:\Apps\Lens

pwsh Scripts/windows/install.ps1 -Action Upgrade `
  -PackageRoot Build/Releases/Windows/Lens-0.1.16-x64 `
  -InstallRoot E:\Apps\Lens

pwsh Scripts/windows/install.ps1 -Action Rollback -InstallRoot E:\Apps\Lens
pwsh Scripts/windows/install.ps1 -Action Uninstall -InstallRoot E:\Apps\Lens
```

该脚本不是签名 EXE 安装器。失败路径：

```powershell
pwsh Scripts/windows/run-installer-stress.ps1 -DataRoot E:\LensInstallerStress
```

## 验证

```powershell
pwsh Scripts/windows/test.ps1 -Suite Unit
```
