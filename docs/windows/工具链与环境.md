## 硬性约束

用户要求：所有下载、缓存和构建产物必须放在 E 盘，不写入 C 盘。本机 Visual Studio 已装在 F 盘、Windows SDK 在 F 盘，符合该方向。后续安装 Rust/CMake 及配置 NuGet/Cargo 缓存时必须显式重定向：

- `RUSTUP_HOME=E:\DevTools\rustup`
- `CARGO_HOME=E:\DevTools\cargo`
- `NUGET_PACKAGES=E:\DevTools\nuget\packages`
- CMake 安装到 `E:\DevTools\CMake`

注：系统组件（Windows SDK 更新、VS 修改、运行时登记）由安装器决定写入位置，无法保证零 C 盘写入；用户已知晓此差异，项目数据、缓存与构建产物仍严格限 E 盘。

## 本机已知差异与注意点

- `Get-ComputerInfo` 显示 `WindowsProductName=Windows 10 Pro`，但 build 26200 与 `Win32_OperatingSystem.Caption`（Windows 11 专业版）确认实际为 Windows 11；脚本以 CIM Caption 为准，避免依赖本地化产品名。
- `Win32_OperatingSystem.OSArchitecture` 是本地化字符串（本机为"64 位"），架构判断改用 `PROCESSOR_ARCHITECTURE`。
- Windows SDK 被重定向到 F 盘，检测必须读 `HKLM\SOFTWARE\Microsoft\Windows Kits\Installed Roots\KitsRoot10`，不能只扫 C 盘默认路径。
