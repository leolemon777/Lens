# 截图窗口与画布修复（UI Review 03）

交付：`Build/Releases/Windows/UI-Review-03/Lens-0.1.0-x64/app`。

## 本轮改变

- Quick Access 根据截屏完成时鼠标所在显示器的工作区定位到右下角，保留边距，避开任务栏；先定位再显示，避免左上角闪现。
- “编辑”打开刚刚截取的素材，并关闭快速访问窗口。
- 编辑页面不再重复放置大型操作中心，把空间留给画布。
- 画布按原始比例显示，绘制期间显示预览，捕获指针避免拖出边界后操作丢失。
- 编辑始终读取原始截图，避免以已标注的预览为底图重复叠加；恢复已保存的背景、比例和留白。
- 增加自选标注颜色、文字内容与字号、0–30% 画布留白。
- 复制、保存与导出的图片不包含选中辅助框；异步复制失败能显示错误。

## Computer Use 实测

- 截图后的快速访问窗口已位于屏幕右下角，未压住任务栏；本机快照报告窗口原点为 (3189, 1836) 物理坐标。
- 点击编辑后打开刚截的 480×300 图片，快速访问窗口关闭。
- 画出矩形，Ctrl+Z 撤销、Ctrl+Shift+Z 重做通过。
- PNG 导出成功，打开文件核对有矩形且没有选中辅助框。
- 画布留白从 8% 调为 18%，点击保存成功；重新加载后恢复 18%，原图和标注没有重复叠加。
