## 2026-09-11 最新修复与复核结论：第一批完成，第二、三批部分完成

本节是当前有效结论，优先级高于下方历史记录中的“全部完成”等表述。此次先重新核查源码并补充能够暴露真实缺陷的回归，再修改实现；没有 reset、clean、覆盖原始媒体或删除现有未提交/未跟踪工作。

### 已实现

1. **录制恢复安全性**
   - `recover_recording_package` 优先读取 `raw/segments/manifest.json`，按日志顺序选择分片；日志有效时不再把目录中未登记的 MP4 混入恢复。日志缺失或不可读时保留旧项目扫描兼容，并在恢复报告中记录原因。
   - 每个候选分片不仅探测容器和时长，还使用 FFmpeg `-xerror` 完整解码视频流；有效前片加损坏尾片会得到 `recoveredPartial`，全部损坏或媒体工具/拼接/混音失败会得到 `recoveryFailed`。
   - 拼接、混音和最终解码均在唯一暂存目录完成；只有最终产物验证成功后才原子发布 `previews/program.mp4`。替换已有预览时保留备份并支持回滚，原始分片不改写。
   - 恢复失败报告和状态写入不再静默忽略错误；失败项目以及部分恢复项目可重试，完整 `ready` 项目拒绝重复恢复。
   - 录制期间持有 `raw/segments/recording.active` 独占句柄；恢复操作会拒绝仍被真实录制进程占用的项目，进程异常退出后留下的普通标记文件不会永久阻断恢复。
   - 更新 manifest 时从原始 JSON 就地修改状态和恢复资产，保留未知顶层字段及既有资产扩展字段。

2. **内嵌音频、画中画与音频处理**
   - 明确音源优先级：存在独立系统声侧轨时使用该侧轨，避免再次混入视频内嵌的同一系统声；没有独立系统声时保留视频内嵌声音；麦克风按配置与选定的系统/内嵌声音混合。
   - 画中画合成继续沿用上述音频选择，不再因只映射视频而丢失内嵌音轨。
   - 运镜渲染现在尊重 `camera.mode`；`off` 即使保留关键帧也不执行变焦。
   - Ducking/normalize 由同一编辑计划进入渲染和导出链路。麦克风先通过 `asplit` 明确拆成侧链控制和可听混音两路；系统声和麦克风在进入 `sidechaincompress` 前先补齐，由最终视频时长统一截断，修复侧链先结束时强闪避尾段偶发静音。Ducking 回归直接测产品产物的系统声频段能量，覆盖讲话期间衰减、停讲恢复、关闭后不处理及不同衰减参数，不再用旁路手写 FFmpeg 命令制造断言对象。

3. **安装资源与失败语义**
   - `frontend_server` 删除编译机 `CARGO_MANIFEST_DIR/../dist` 运行时兜底，使用显式环境变量、可执行文件相对的 `dist` 或资源目录。
   - NSIS 包含 `dist/`、`lens-worker.exe`、`ffmpeg.exe`、`ffprobe.exe` 和 `THIRD_PARTY_LICENSES.md`；发布清单记录逐文件大小及 SHA-256。
   - 打包脚本使用独占锁防止并发覆盖，要求所有资源存在，要求安装器达到合理体积，并且仅在全部构建、打包和清单计算成功后替换发布目录。多次故意/环境触发的打包失败均返回失败，旧发布目录未被冒充更新。
   - 许可证记录已按实际二进制配置修正：当前 Gyan FFmpeg 构建启用了 GPL/version3，不能标成仅 LGPL。新增离线 NOTICE 生成器，针对 Windows x64 从 Cargo/npm 锁定依赖生成 277 个 Rust 包、61 个 npm 包、174 份去重许可证/NOTICE 正文及 FFmpeg 版本、构建配置和工具哈希；缺少许可证元数据时打包失败。

4. **Worker 与增量索引的本轮改进**
   - 导出和渲染已通过独立 `lens-worker.exe` 路由，并具有握手、总超时、进程失败后重启重试和退出处理；宿主删除了 worker 失败后悄悄退回进程内渲染的路径，失败会明确报告为可重试错误。
   - 前端为每次渲染/导出生成稳定任务 ID，并显示“取消当前任务”；宿主登记任务状态并提供查询/取消命令。取消令牌由 worker 客户端每 50ms 检查，取消或超时时在 Windows 上终止 worker 整个进程树，避免遗留 FFmpeg 子进程，并且取消任务不会自动重试。
   - 同一项目不允许并发渲染/导出。worker 使用任务 ID 创建专属暂存目录；异常、超时和取消后只清理该任务目录，不碰其他任务或原始素材。正常完成后优先发送 `shutdown` 并等待优雅退出。
   - 索引指纹跟踪 manifest、人工字幕、分析字幕、OCR、转写、insights、预览和主屏幕媒体；在大小和纳秒时间之外加入实际内容哈希及缺失标记，解决同秒、同大小连续修改不刷新问题。

5. **跨版本 JSON 写回保真**
   - 录制结束不再重建并覆盖 manifest：保留原 `createdAt`，递归保留未知顶层字段、嵌套对象字段和匹配资产的扩展字段；未知资产角色继续保留，已失效的 Windows 托管素材不会被错误复活。
   - 时间线、截图编辑计划和自动编辑计划的所有桌面写回路径改为扩展字段保留写入；数组按 `id`、任务 ID、素材身份或时间身份匹配，已删除片段不会因合并被重新加入。
