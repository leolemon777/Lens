# 任务 1 ·【Bug】轻量导出把画面降到 568×320

## 1.1 问题

`Sources/ScreenTraceMac/Capture/VideoExportProfile.swift` 里 `.compact`（用户界面上的「轻量」）使用了 `AVAssetExportPresetMediumQuality`。

这个 preset **不是**「同分辨率、低码率」，它是 Apple 的设备自适应**质量**档，会直接改分辨率。已实测确认：

```
源 1920x1080 →
  AVAssetExportPresetHighestQuality      → 1920x1080   284 KiB   ✓
  AVAssetExportPresetMediumQuality       →  568x320    148 KiB   ✗  ← 现状
  AVAssetExportPresetHEVCHighestQuality  → 1920x1080   184 KiB   ✓  ← 目标
```

即使把 `videoComposition.renderSize` 显式设成源尺寸，MediumQuality 依然会降到 568×320。对录屏工具来说这等于文字全部不可读。

影响两条导出路径：
- `Sources/ScreenTraceMac/Capture/AutoPreviewRenderer.swift:318`
- `Sources/ScreenTraceMac/Capture/AudioMixdownRenderer.swift:272`

两处都读同一个 `exportProfile.assetExportPresetName`，所以**只需改 `VideoExportProfile.swift` 一处**，这两条路径同时被修好。不要去改那两个渲染器。

# 任务 2a ·【必做】转写分片重叠从 1 秒放宽到 4 秒

## 2a.1 问题

`Sources/ScreenTraceCore/TranscriptChunking.swift:43` 的默认重叠是 1 秒：

```swift
public static func plan(
    durationSeconds: Double,
    maximumChunkDurationSeconds: Double = 50,
    overlapSeconds: Double = 1
) -> [TranscriptChunk] {
```

而 `Sources/ScreenTraceMac/Capture/LocalSpeechTranscriptionService.swift:105` 用的就是默认值：
```swift
let chunks = TranscriptChunkPlanner.plan(durationSeconds: duration)
```

后果：分片 N 覆盖 `[0, 50]`，分片 N+1 从 `49` 开始，归属边界在 `49.5`。一句 2 秒的话跨在 `48.6 → 50.6`：分片 N 完整听到了它，分片 N+1 只听到后 1.6 秒，但中点 `49.6 > 49.5` 会把它判给 N+1，**残句胜出**。中文语音 segment 常在 2–5 秒，正好卡在这个区间。

重叠放宽到 4 秒后，两侧各有 2 秒余量，绝大多数跨界句子在两个分片里都被完整听到，中点规则挑哪个都是完整的。

# 任务 2b ·【可选】分片归属优先「完整听到」的一方

> **如果你对这一步没有十足把握，跳过它。** 任务 2a 已经解决了绝大部分问题，2b 只是补掉超过 4 秒的超长跨界句子这一小类。做错了会破坏当前正确的「不重不漏」性质。

## 2b.1 目标

当前 `TranscriptChunkMerger.merge` 只用中点归属。要加一条：**如果某个 segment 在它所属的分片里是被截断的，而相邻分片完整听到了它，则采用完整的那份。**

## 2b.2 改动

编辑 `Sources/ScreenTraceCore/TranscriptChunking.swift` 的 `TranscriptChunkMerger.merge`。

把现有的整个 `for (documentIndex, item) in ordered.enumerated() { ... }` 循环体
（从 `let includesUpperBoundary = ...` 到该 for 循环结束的 `}`）替换为：

```swift
        struct Candidate {
            let segment: TranscriptSegment
            let isFullyHeard: Bool
            let ownedByMidpoint: Bool
        }
        var candidates: [Candidate] = []

        for (documentIndex, item) in ordered.enumerated() {
            let isFirstChunk = documentIndex == 0
            let includesUpperBoundary = documentIndex == ordered.count - 1
            for segment in item.document.segments {
                let start = item.chunk.sourceStartSeconds + segment.startSeconds
                let rawEnd = item.chunk.sourceStartSeconds + segment.endSeconds
                let end = min(rawEnd, item.chunk.sourceEndSeconds)
                let midpoint = start + max(end - start, 0) / 2
                let isAfterLowerBoundary = midpoint >= item.chunk.acceptedStartSeconds
                let isBeforeUpperBoundary = includesUpperBoundary
                    ? midpoint <= item.chunk.acceptedEndSeconds
                    : midpoint < item.chunk.acceptedEndSeconds
                // A segment flush against a chunk's own edge was cut off by the
                // slice, not by the speaker. Only the interior of a chunk can be
                // trusted to hold a complete utterance.
                let clippedAtStart = !isFirstChunk && segment.startSeconds <= 0.001
                let clippedAtEnd = !includesUpperBoundary
                    && rawEnd >= item.chunk.sourceDurationSeconds - 0.001
                candidates.append(Candidate(
                    segment: TranscriptSegment(
                        startSeconds: start,
                        endSeconds: end,
                        text: segment.text,
                        confidence: segment.confidence
                    ),
                    isFullyHeard: !clippedAtStart && !clippedAtEnd,
                    ownedByMidpoint: isAfterLowerBoundary && isBeforeUpperBoundary
                ))
            }
        }

        // Prefer the midpoint owner, but let a neighbour that actually heard the
        // whole utterance replace a truncated winner covering the same instant.
        let accepted = candidates.filter(\.ownedByMidpoint)
        for candidate in accepted {
            if candidate.isFullyHeard {
                mergedSegments.append(candidate.segment)
                continue
            }
            let replacement = candidates.first {
                !$0.ownedByMidpoint
                    && $0.isFullyHeard
                    && $0.segment.startSeconds <= candidate.segment.startSeconds + 0.35
                    && $0.segment.endSeconds >= candidate.segment.endSeconds - 0.35
            }
            mergedSegments.append(replacement?.segment ?? candidate.segment)
        }
```

# 任务 3 ·【必做】长截图匹配加次优比校验

## 3.1 问题

`Sources/ScreenTraceMac/Capture/VerticalScrollingCaptureAssembler.swift:117`：

```swift
guard let signatureDelta = estimate.deltaRows,
      estimate.bestDifference <= 0.145 else {
    return .rejected(bestDifference: estimate.bestDifference)
}
```

接受判据只有一条：最优匹配的绝对差值够小。但滚动匹配的经典失败模式不是「最优不够好」，而是「**有好几个同样好的最优**」——表格、列表、卡片流、等宽代码里，行与行长得几乎一样，delta=20 和 delta=60 可能都算出 0.05 的差值。此时 [297-308] 的循环取第一个最小值，选错了也照样 ≤ 0.145 直接接受，拼出来的长图会**重复或丢失一屏内容**。

解决办法是 Lowe ratio test：最优必须**显著优于**与它相距较远的次优，否则判定为歧义，跳过这一帧等下一帧（520ms 后就有）。跳一帧远比拼错一屏便宜。

## 3.2 第一步：先写测试

编辑 `Tests/ScreenTraceMacTests/VerticalScrollingCaptureAssemblerTests.swift`，新增：

```swift
    /// A page of identical repeating rows makes several scroll offsets score
    /// almost the same. Accepting the first minimum silently duplicates or drops
    /// a screenful, so an ambiguous frame must be skipped instead of stitched.
    func testAmbiguousRepeatingRowsAreSkippedInsteadOfStitchedAtAGuess() throws {
        let assembler = VerticalScrollingCaptureAssembler()
        // Perfectly periodic stripes: every candidate offset that is a multiple

    /// Both read the same text, so letting the summary fall back to "the first
    /// two sentences" made it strictly weaker than the key points beside it.
    private static func rankedSentences(

        minimumCharacters: Int

        let candidates = sentences.enumerated().compactMap { index, sentence -> (Int, String, [String])? in
            let sentence = normalizedWhitespace(sentence)

            return (index, sentence, semanticTokens(in: sentence))

            for token in Set(candidate.2) { frequency[token, default: 0] += 1 }
        }
        return candidates.map { candidate in
            let tokenScore = candidate.2.reduce(0.0) {
                $0 + Double(frequency[$1, default: 0])

            let positionBonus = max(0, 0.8 - Double(candidate.0) * 0.08)

                text: candidate.1,
                score: tokenScore + positionBonus

            if $0.score != $1.score { return $0.score > $1.score }
            return $0.index < $1.index

    /// ISO 7064 MOD 11-2, the checksum carried by an 18-digit mainland identity
    /// card. Without it every eighteen-digit order number or timestamp run gets
    /// reported, and a panel full of false positives is one users stop reading.
    private static func passesIdentityCardChecksum(_ rawValue: String) -> Bool {
        let digits = Array(rawValue.uppercased())
        guard digits.count == 18 else { return false }
        let weights = [7, 9, 10, 5, 8, 4, 2, 1, 6, 3, 7, 9, 10, 5, 8, 4, 2]

        for (weight, character) in zip(weights, digits.prefix(17)) {
            guard let value = character.wholeNumberValue else { return false }
            sum += weight * value
        }
        return checkCharacters[sum % 11] == digits[17]
    }

/// Word segmentation for languages without spaces. The core stays portable, so
/// the default is a dependency-free bigram fallback; platform layers inject a
/// real segmenter. Keeping this behind a protocol lets the future Rust worker
/// supply its own without changing the organizer.
public protocol TraceTokenizing: Sendable {
    func words(in text: String) -> [String]
}

public struct BigramTokenizer: TraceTokenizing {
    public init() {}

    public func words(in text: String) -> [String] {
        var result: [String] = []
        guard let regex = try? NSRegularExpression(pattern: #"\p{Han}{2,}"#) else {
            return result
        }
        let range = NSRange(text.startIndex..<text.endIndex, in: text)
        for match in regex.matches(in: text, range: range) {
            guard let swiftRange = Range(match.range, in: text) else { continue }
            let characters = Array(text[swiftRange])
            if characters.count <= 6 { result.append(String(characters)) }
            guard characters.count >= 2 else { continue }
            for index in 0..<(characters.count - 1) {
                result.append(String(characters[index...index + 1]))
            }
        }
        return result
    }
}

    func words(in text: String) -> [String] {
        guard !text.isEmpty else { return [] }
        let tagger = NLTagger(tagSchemes: [.lexicalClass])
        tagger.string = text
        var result: [String] = []
        let keptClasses: Set<NLTag> = [.noun, .verb, .adjective, .otherWord]
        tagger.enumerateTags(
            in: text.startIndex..<text.endIndex,
            unit: .word,
            scheme: .lexicalClass,
            options: [.omitPunctuation, .omitWhitespace, .omitOther]
        ) { tag, range in
            let word = String(text[range])
            guard word.count >= 2,
                  let tag, keptClasses.contains(tag) else { return true }
            result.append(word)
            return true
        }
        return result
    }
}
```
