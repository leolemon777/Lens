在同文件加私有辅助方法（解释为什么去掉日期）：

```swift
    /// Dated "截图 …" titles make the library unsearchable once a day has
    /// more than a handful of captures. A window screenshot already knows the
    /// app and document name at capture time, so use that instead of waiting
    /// for OCR.
    private static func screenshotTitle(
        prefix: String,
        captureSource: ScreenshotCaptureMetadata?,
        createdAt: Date
    ) -> String {
        let application = captureSource?.applicationName ?? ""
        let windowTitle = captureSource?.windowTitle ?? ""
        if !application.isEmpty, !windowTitle.isEmpty, windowTitle != application {
            return String("\(application) · \(windowTitle)".prefix(46))
        }
        if !application.isEmpty {
            return String(application.prefix(46))
        }
        let resolvedPrefix = prefix.isEmpty ? "截图" : prefix
        return "\(resolvedPrefix) \(displayTimestamp.string(from: createdAt))"
    }
```

# 任务 4 · 整理标题拒绝「截图+日期」和日历碎片

## 4.1 问题

`LocalLensOrganizer.suggestedTitle` 的回落链是：第一句 OCR → 录屏 `captureSource.windowTitle` → `manifest.title`。

两处失效：

1. 截图身份在 `screenshotCaptureSource`，不在 `captureSource`，所以窗口标题这条链对截图是空的。
2. 第一句 OCR 经常是日历/表头碎片（真实项目出现过标题「8月」、摘要「七月初四 日一二三四五六」）。`cleanTitle` 只剥标点，不判断是否像一份捕获日期标题或无意义短标签。

## 4.2 第一步：先写测试

# 附录 A · 做完之后怎么验

自动化：每个任务的 `swift test` 必须 0 失败。

人工（仍不可省略）：

1. 录一段选「自然成片」的窗口录屏，打开 `edits/edit-plan.json`，确认 `"export": { "preset": "balanced" }`；`previews/auto.mp4` 分辨率等于源，编码是 H.264 不是 HEVC。
2. 选「教学讲解」再录一次，确认字幕默认是开的。
3. 截一个 Safari / Cursor 窗口，库里的标题应是「Safari · …」或应用名，而不是「截图 2026年…」。
4. 截一张日历或只有「8月」的小图，整理后标题不应再是「8月」。

不在本单范围：安装到 `/Applications`、Developer ID、公证、任务 6 运镜重写入库。那些是「能给别人用」的下一层，不是「默认就能发」。
