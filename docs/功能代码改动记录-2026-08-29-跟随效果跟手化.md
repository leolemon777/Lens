# 功能代码改动记录——跟随效果跟手化（2026-08-29）

## 背景与问题

用户反馈：鼠标点动时的跟随效果"完全拖拽、有延迟、留影子、实时性跟不上"。
诊断结论（非单一 bug，是三层算法叠加的默认值取向问题）：

1. **指针跟随运镜过于克制**：默认 natural 预设走 restrained 档——指针跑出
   画面中心 ±31% 才触发跟随、0.24s 采样一次、平移限速 0.22 视口/s、
   加速度限 0.50/s²，快速移动时镜头 1 秒以上才追上；
2. **影子默认开启**：presentation 预设光标 `.trail`（4 个渐隐模糊幽灵拷贝）、
   teaching 用 `.spotlight`、natural/教学均叠 0.12–0.16 的运镜动态模糊；
3. **光标平滑窗口偏大**：42–52ms 求值平滑叠加路径平滑，慢速移动有可感滞后。

取向决定：全面跟手化（成片风格从"电影感"转向"跟手"，效果仍可在编辑器手动调回）。

### CameraMotionComfortLimits（`CameraMotionComfortAnalyzer.swift`）

recommended(for:) 三档同步放宽：pan 0.75/1.00/1.40 → 1.30/1.75/2.40，
zoom 1.25/1.60/2.40 → 2.10/2.70/3.60。
原因：转场时长钳制下平移峰值可达 `距离/上限×1.875×平均scale`，
旧阈值会立即把新规划判为不舒适；按规划器实际可达峰值重新校准。
