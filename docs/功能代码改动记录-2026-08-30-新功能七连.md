# 功能代码改动记录：新功能七连（2026-08-30 第二批）

日期：2026-08-30
状态：已实现，全量测试通过（605 例，0 失败），签名构建成功
来源：[两轮调研合并总结](../research/调研总结-2026-08-29-两轮合并.md) P0 剩余三项 + P1 五项。全部按"自动成片器"试金石实现——**每项都在缩短"不打开编辑器也能直接用"的路径，而不是增加编辑能力**。

## 一、敏感信息遮挡闭环（P0）

- **LensCore** `SensitiveRedactionPlanner`（新）：对 OCR 每个 block 跑 `LocalLensOrganizer.sensitiveMatches`（已公开，5 类 + 校验码），命中按字符比例映射到 block 的归一化框内，合并相邻命中，生成带余量的 `.pixelate` 标注（高强度 0.05）。
- **LensMac**：截图编辑器打开时自动检测，工具栏出现"**遮挡 N 处敏感信息**"一键按钮；插入的标注是普通对象——可移动、可调、可删、可撤销。`ScreenshotAnnotationEditorModel` 加 `suggestedRedactions` 通路，控制器传 OCR。
- 红线备忘：调研共识"像素化可被还原"；如需不可逆，用户可改用矩形填充标注。后续可加"遮挡方式"选项。

## 二、一键音频增强（P0）

- **LensCore** `AutoEditPlan.Audio.VoiceEnhancementLevel`（轻/标准/强）：只重映射现有混音字段（降噪强度/目标响度），不新增渲染路径。
- **LensMac**：声音区顶部"一键人声增强"开关 + 三档分段选择器 + "**试听未处理**"开关（临时旁通三项处理走同一预览管线做 A/B，关闭即恢复，经撤销栈）。
- 逐参数滑条保留在下方——一键是入口，不是替代。

## 三、多画幅重构（P0）

- **LensCore** `AutoEditPlan.Export.AspectRatio`（vertical9x16 / square1x1，nil=跟随源）。
- **LensMac** `AutoPreviewRenderer`：
  - `deliverySize(source:aspectRatio:)` 由源高导出目标宽（偶数化），显式写 `videoComposition.renderSize`；
  - `renderFrame` 取景数学通用化：**contain 基准缩放 × 运镜缩放**——zoom=1 时内容完整居中、上下以画布背景中点色填充（黑边变包装），zoom 增大后按 center 裁切进入内容；**画幅一致时数学退化为原有行为**（全部 14 个既有渲染测试零改动通过）。
  - 每轴独立 clamp：视口超出源的轴自动居中。
- UI：导出区"导出画幅"分段选择（跟随源/竖屏 9:16/方形 1:1），切换即重渲。
- 测试：端到端（640×360 源 → 202×360 竖屏成片）+ 纯函数 4 断言组。

## 四、逐词高亮字幕（P1，盯住滑坡的一项）

- **LensCore** `Captions.highlightsSpokenWords`（自定义解码，旧计划兼容为 false）+ `CaptionWordSegmenter`（CJK 单字/拉丁整词，与口头禅规划器共享 CJK 判定）+ `CaptionCue.spokenCharacterFraction/spokenWordIndex`（cue 内线性插值——转写只有分段级时间戳，与 `CaptionCueEditor.split` 的既有近似一致）。
- **LensMac** `CaptionOverlayRenderer`：按词 run 双色绘制（当前词品牌青色），缓存键含词序。UI 只有一个"逐词高亮"开关——**没有样式编辑器**。

## 五、击键胶囊（P1）

- **LensCore** `KeystrokePlanner` + `AutoEditPlan.KeystrokeDisplay` + `Interaction.showsKeystrokes/keystrokes`（自定义解码，旧计划默认关/空）。`⌘⇧S` 式文案，重复触发过滤。
- **隐私是结构性的**：录制端白名单只落盘快捷键与非文本控制键（`sanitizedKeyboardEvent`，既有行为），纯文字输入永远无法进入胶囊——不需要"密码过滤"这种补丁。
- **LensMac** `AutoPreviewRenderer.applyKeystrokes`：画布层之上的右下角胶囊（纯 CGContext，合成器后台线程安全），淡入淡出、最近三条并排、NSCache 缓存。`writeAutoEditPlan` 录制完成即生成；编辑器打开时为旧项目懒补生成。
- UI：光标与点击区"显示按键"开关。

## 六、一键步骤文档（P1）

- **LensCore** `StepDocumentPlanner` + `StepDocument`：连击合并（1.2s 窗口）、窗口事件带出应用上下文（"在 Safari 中点击"）、双击/右键动词区分、九宫格位置描述、Markdown 输出（每步引用 step-NN.png）。
- **LensMac** `StepDocumentExporter`：`AVAssetImageGenerator` 逐帧提取原始画面（非成片，无运镜干扰）→ 每步 PNG + Markdown。入口在编辑器导出区"导出步骤文档…"。预留了 Camtasia 式"步骤转视频"的扩展位（Step 结构带源时间）。

## 七、TTS 配音草稿 + 代码截图卡片（P1）

- **NarrationSpeechSynthesizer**：系统语音（AVSpeechSynthesizer.write → CAF），脚本生成时剔除语气粒子（复用词分段器），全离线。入口：字幕区"导出配音草稿…"，产物存包内 `previews/narration-draft.caf`。这是零依赖的起步层；与混音管的自动集成留待后续。
- **CodeCardRenderer**：OCR 文本 → 深色等宽卡片（行号、Menlo、窗口条），`isLikelyCode` 启发式（≥3 行 + 代码信号）决定按钮出现。入口：截图编辑器"导出代码卡片"（ray.so 形态的本地版）。

## 已知边界（真机待验证）

- 竖屏 contain 布局的黑边在无画布时用近黑填充；开启画布后为渐变中点色——连续性可接受但非逐像素匹配。
- 击键胶囊每帧 CoreText 绘制仅在胶囊活动窗口内发生（窗口外零成本），缓存命中后为位图合成。
