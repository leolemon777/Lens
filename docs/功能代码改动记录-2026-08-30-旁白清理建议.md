# 功能代码改动记录：旁白清理建议（静默 / 口头禅 / 开头结尾空白）

日期：2026-08-30
状态：已实现，全量测试通过（581 例，0 失败），待真机体验验证
来源：[两轮调研合并总结](../research/调研总结-2026-08-29-两轮合并.md) P0 第一项——静默/口误/酝酿声清除是全行业标配且口碑"低风险高回报"；社区共识是**选择性移除**（可逐条接受/拒绝），全自动删除会显得"跳"。

## 用户可见行为

- 打开带麦克风轨的录屏项目，编辑器检查器出现**"旁白清理"**分区。
- 首次打开时后台分析一次（阈值与 ducking 共用 `narrationThresholdDecibels`，默认 −42 dB），生成三类建议：
  - **静默段**：两段语音之间 ≥0.6s 的停顿，前后各保留 0.18s 余量，避免切到起音；
  - **口头禅**：转写文本中的语气粒子（嗯/啊/呃/哦/唉/哎/欸/唔/呣 + um/uh/erm/hmm 等），按字符位置在转写分段内线性插值出时间；词表刻意保守，"然后/就是/like"这类连接词不标（删了会跳）；
  - **开头/结尾空白**：首句前 ≥0.8s（保留 0.35s 引导）、末句后 ≥1.2s（保留 0.6s 收尾）。
- 每条建议可**接受**（从时间线剪除该区间）、**跳过**（忽略，可"撤销跳过"）；顶部有**全部接受**与"共 N 条 · 可缩短约 X 秒"摘要。
- 点击建议行会把播放头定位到对应输出时间。
- 一切走非破坏模型：剪除 = 时间线分段禁用（可撤销/重启用），原始媒体永不动。

## 已知边界

- 词表契约：中文按**单字**匹配，英文按整词（小写）匹配；双字词（如"嗯嗯"）不会被匹配。
- 分析失败（音频格式异常等）按"已审阅、无建议"处理（空数组落盘），避免每次打开重试；不与错误提示联动。
- 口头禅时间是对转写分段内位置的线性插值（SFSpeechRecognizer 提供分段级时间戳），极短分段的定位精度受此限制。
- 真机体验项：−42 dB 阈值在嘈杂环境/低增益麦克下的误检率；建议列表在中等规模（数十条建议）下的滚动性能。
