# 屏迹 macOS 发布检查清单

状态：Public Alpha/Beta 前必须逐项留存证据。本清单不把本地 ad-hoc 签名视为发布签名。

## 1. 发布范围与法务

- [ ] 确定版本号、构建号、发布级别和支持的最低 macOS 版本。
- [ ] 选定开源许可证，在根目录添加 `LICENSE`，审查所有依赖与媒体资产许可。
- [ ] 复核 `Assets/AppIcon.png` 的小尺寸辨识度、固定摘要、来源记录与最终品牌决策，并确认构建包含有效 `AppIcon.icns`。
- [ ] `bash Scripts/audit-public-source.sh` 通过，并复核 `docs/第三方依赖与素材清单.md` 与当前构建一致。
- [ ] 确认 `README.md`、`PRIVACY.md`、`SECURITY.md` 和 `CONTRIBUTING.md` 与当前二进制行为一致。
- [ ] 配置私密安全报告通道与公开支持联系方式。
- [ ] 从版本控制和发布附件中排除真实截图、录屏、声音、崩溃报告、项目包与签名/公证凭据。

## 2. 代码与项目格式

- [ ] `git status --short` 为空，发布 commit 已标记。
- [ ] `docs/屏迹开放项目格式-v0.1.md` 与 `TraceProjectSchema.portableDocuments` 一致，所有可移植 JSON 文档的最低可读和当前写入版本均已记录。
- [ ] `ProjectSchemaCompatibilityTests` 使用旧版录屏/截图黄金样本验证读取字节不变，并验证未来或畸形 schema 被拒绝且不会进入屏迹库。
- [ ] 损坏索引可重建，中断录制可发现，原始媒体和分片不被恢复流程删除。

## 3. 自动化门槛

- [ ] `swift test` 全量通过，测试总数和结果写入发布记录。
- [ ] `swift build -c release --product ScreenTrace -Xswiftc -warnings-as-errors` 通过。
- [ ] `bash Scripts/build-release-artifacts.sh` 通过 Info.plist、签名结构、dSYM UUID 一致性和 zip 完整性检查。
- [ ] `bash Scripts/package-macos-release.sh` 生成 DMG、App zip、dSYM、机器可读发布清单与 SHA-256 清单，DMG 重新挂载后 App 仍通过严格验签且 Applications 链接正确。
- [ ] 记录 App/dSYM Mach-O UUID 与符号包 SHA-256，并使用匹配 UUID 的合成 `.ips` 验证离线符号化。
- [ ] 真实 H.264、音频混合、摄像头画中画、转场、字幕、标注、PNG/JPEG、OCR 和长截图集成测试全部在发布环境通过。

## 4. 解锁 Mac 真机验收

- [ ] 固定签名身份后重新授予屏幕与系统音频录制、麦克风、摄像头、语音识别与辅助功能权限。
- [ ] 使用内置键盘、Magic Keyboard 和第三方键盘验证 `Fn + Control`、`Fn + Space`、自定义和无 Fn 备用快捷键。
- [ ] 在单屏、多屏、Retina/非 Retina 混合缩放与不同排列下完成区域、窗口、多窗口和当前显示器截图。
- [ ] 在 Safari、Chrome 和普通 App 中验证长截图、OCR、标注、背景编辑、贴图和 PNG/JPEG 导出。
- [ ] 验证区域、窗口和显示器录制的系统声/麦克风/摄像头分轨、暂停/继续、丢弃并重录和原始 MP4 快速可用。
- [ ] 完成自动缩放、平滑光标、点击效果、画中画、转场、字幕、转写、整理、视频标注和三档导出的成片视觉验收。
- [ ] 进行 10 分钟、1 小时录制，以及强退、磁盘不足、设备拔出、系统流中断和恢复测试。
- [ ] 在浅色/深色、降低透明度、增强对比度、减少动态效果、VoiceOver 和键盘导航下完成无障碍验收。

## 5. 安装、升级与恢复

- [ ] 在干净用户账户完成首次安装、权限引导、首张截图、首次录屏和首次导出。
- [ ] 从上一个公开版本覆盖升级，验证快捷键、媒体偏好、权限、旧项目和索引兼容。
- [ ] 验证未授权、授权被撤回、App 替换签名、项目包只读、磁盘写入失败与损坏索引的可恢复引导。
- [ ] 验证卸载说明不会误删 `~/Pictures/ScreenTrace/` 中的用户项目，完全清理需显式列出数据目录。

## 6. 签名、公证与分发

- [ ] 通过 `SCREENTRACE_SIGNING_IDENTITY`、`SCREENTRACE_VERSION` 和 `SCREENTRACE_BUILD_NUMBER` 使用固定 Bundle ID `app.screentrace.mac` 与 Developer ID Application 证书生成 Release App。
- [ ] 使用 `codesign --verify --deep --strict --verbose=2` 校验 App，用 `spctl --assess --type execute --verbose=4` 验证 Gatekeeper。
- [ ] 使用 `SCREENTRACE_NOTARY_PROFILE` 指定钥匙串 profile，由打包脚本用 `notarytool` 提交并等待 Accepted，再用 `stapler` 固定与验证票据；断网状态下复核固定结果。
- [ ] 生成可安装 DMG 或签名 PKG，在另一台未安装开发证书的 Mac 上验证。
- [ ] 复核 `release.json` 中工作区为 `clean`、签名为 `developer-id`、Team ID 正确、App/DMG 公证均为 `Accepted`，并确认版本、构建号、最低系统、Mach-O UUID、制品尺寸、SHA-256 和公证 request ID 与本次发布一致。
- [ ] 配置自动更新前完成签名键管理、更新包签名、降级/回滚和断网/损坏更新包测试。

## 7. 发布与回滚

- [ ] 发布说明列出已知问题、权限需求、数据路径、项目格式兼容性和校验和。
- [ ] 上传 App/安装包、dSYM、`release.json`、校验和文件与发布说明，保留与该 commit 匹配的不可变备份。
- [ ] 公开下载后从公网重新下载，比对 SHA-256，完成安装、启动、捕获、导出和更新冒烟。
- [ ] 预先准备撤回下载、回滚至上一稳定版本、保留用户原始项目和发布安全公告的操作步骤。
