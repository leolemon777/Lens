# 屏迹品牌资产说明

## App 图标

- 源文件：`Assets/AppIcon.png`
- 用途：macOS App 图标唯一主图；构建脚本从该文件生成标准多尺寸 `AppIcon.icns`，派生文件不进入 Git。
- 规格：1024×1024、RGB、不透明 PNG。
- SHA-256：`92588341cd37aef36689b86e4bd6e41f19b8acca6533fb945fbf2b41e91e443d`
- 设计语义：四个圆角取景角标表示精确捕获；青色流线与光标箭头表示屏幕操作轨迹、平滑光标和自动运镜；珊瑚色圆点表示录制状态；烟黑液态玻璃对应“迹光玻璃”视觉规范。
- 来源：2026-08-10 为屏迹项目使用 OpenAI 内置图像生成工具原创生成，未使用第三方参考图、Logo、字体或素材。公开发布前仍应由项目所有者确认所使用服务条款、商标检索和最终品牌决策。
- 小尺寸验收：2026-08-11 已检查 128、32 和 16 像素派生图，取景角标、青色轨迹/光标和珊瑚色录制点均可辨识；1024 像素主图已确认为 RGB 不透明 PNG。

生成使用的最终提示词：

```text

combining four rounded capture-frame corners with one elegant flowing motion
trace. Use restrained liquid-glass depth, graphite glass, ice cyan/electric blue,

```

## 变更规则

- 替换主图时必须同步更新本文件和 `Scripts/audit-public-source.sh` 中的 SHA-256，并重新检查 16、32、128 和 1024 像素显示效果。
- 不得把竞品截图、竞品 Logo、Apple Logo、未获授权字体或模板素材合入图标。
- 发布包应检查 `Contents/Resources/AppIcon.icns` 非空、`CFBundleIconFile` 指向 `AppIcon`，且签名后资源校验通过。
