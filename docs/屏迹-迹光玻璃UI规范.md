# 屏迹：“迹光玻璃”UI 与交互规范

版本：v0.3
日期：2026-08-09

## 北极星

屏迹应像 Apple 为 macOS 设计的一款第一方效率工具：安静、精确、瞬时响应，玻璃会随内容与状态自然变化。玻璃是控制界面，不是装饰滤镜。

## 原则

1. 原生优先：关键表面使用 Swift、AppKit、SwiftUI；macOS 26 使用系统玻璃能力，旧版本使用原生材质降级。
2. 内容优先：截图、录屏和画布保持稳定、清晰、色彩可信。
3. 渐进披露：最高频动作直接可见，高级设置在长按、展开或检查器中出现。
4. 连续形变：操作中心、录制状态和完成状态尽量由同一玻璃岛形变衔接。
5. 克制用色：中性银白/烟黑为主；颜色来自内容、状态和录制红，不使用廉价蓝紫霓虹。
6. 可访问：支持深浅色、降低透明度、增强对比度、减少动态效果和完整键盘操作。

## 第一批四个表面

### `Fn + Space` 操作中心

- 屏幕中央或当前活跃屏幕中央出现紧凑玻璃岛；
- 第一层：截图、录屏、OCR、长截图、贴图；
- 第二层：最近 Trace 与复制、拖拽、分享、AI 操作；
- 再按快捷键或 `Esc` 关闭；支持方向键、数字键和回车；
- 录制中打开时直接形变为录制控制中心。

### `Fn + Control` 捕获层

- 屏幕轻度压暗，目标内容仍然可辨；
- 选区使用细亮玻璃轮廓和清晰控制点；
- 尺寸胶囊贴近选区但不遮挡指针；
- 完成后先复制与保存，再出现 Quick Access；
- 标注工具条从选区边缘展开，不跳入主编辑器。

### 录制控制条

- 烟黑玻璃胶囊；录制红点、计时、音频电平、暂停和停止；
- 显示来源、摄像头、磁盘或异常，但正常状态不堆文字；
- 录制开始有明确三秒倒计时和边界确认；
- 停止后形变为完成状态，原始视频立即可打开。

### Quick Access

- 清晰缩略图配玻璃动作轨；
- 默认提供拖拽、复制、标注、贴图、分享和关闭；
- 多次捕获形成可展开的轻量堆栈；
- 自动处理时显示非阻塞进度，原始素材始终可以操作。

### 成片字幕

- 默认使用真实背景模糊、半透明烟黑底与细亮边，不用假渐变代替玻璃；
- 字幕位于成片安全区，与底部/顶部画中画共存时自动缩窄可用区域；
- 默认玻璃，同时提供无底简洁与高对比降级样式；
- 字号、顶部/居中/底部位置及文字校对都是非破坏性编辑，原始转写始终保留；
- 剪切、重排、变速时先重算字幕时间，再烧录到预览。

### 视频编辑画布

- 预览画布跟随原始素材比例，竖屏、方形和超宽屏不用固定 16:9 假画布；
- 摄像头人像使用真实轨道缩略图，可在画布直接拖动，右下角控制点缩放；轨道不可读时使用原生玻璃占位；
- 选中态使用细青色轮廓、内侧亮边和紧凑手势标签，不用粗重视频软件包围框；
- 连续拖动或缩放合并为一次撤销；直接操作期间暂停自动避让，松手后恢复当前避让规则；
- 关键帧在时间线使用菱形标记，提供前后跳转、新增/更新/删除和过渡选择，位置与尺寸始终绑定源时间；
- 字幕出现前人像先平滑预动，字幕结束后再回落；点击聚焦只在实际成片位置与人像冲突时触发避让；
- 编辑器、字幕安全区和导出渲染必须调用同一放置规则，避免所见非所得。

### 屏迹库与本地整理

- 卡片优先显示整理层标题、两行摘要和前三个标签，不改变 Manifest 原始标题；
- 整理详情使用紧凑玻璃面板呈现摘要、标签、要点、章节和仅含掩码的敏感信息提示；
- 人工校正标题、摘要与标签时明确说明只修改整理层；重新生成保留校正，并提供显式“恢复自动”；
- 自动 OCR、转写和整理均在捕获可用之后后台执行，不能延迟剪贴板、Quick Access 或原始录屏落盘；
- 多个自动转写任务串行执行；进度属于对应卡片，不使用阻塞全局模态框。

## 动效基线

- 快速反馈：按下与悬停必须即时；
- 面板出现/消失使用短促弹簧，状态切换使用连续形变；
- 捕获时不使用长入场动画；
- 减少动态效果开启后改为淡入淡出；
- 动效不能延迟剪贴板、保存、录制开始或停止。

## 验收

- 不阅读说明即可完成一次截图、一次录制和一次导出；
- 所有首层动作可只用键盘完成；
- 在浅色、深色、复杂壁纸和降低透明度下均清晰可读；
- 捕获 Agent 空闲时无可感知 CPU 占用；
- 玻璃视觉失败或降级不影响任何捕获功能。
