## 已完成的本机 UI 冒烟测试

- 操作中心可启动并显示原生迹光玻璃界面；
- 辅助功能树能识别主要按钮；
- `Esc` 可关闭操作中心；
- 缺少屏幕录制权限时能进入权限说明流程；
- 录制控制条能获得焦点、计时、切换控制状态并关闭；
- 修复了录制控制条没有成为 key window 的问题。

本轮新增的截图模式菜单、窗口悬停层、权限中心、选区 OCR、标注编辑器和屏迹库尚未完成 Computer Use 回归：本机处于锁屏状态，自动化遵循安全边界，没有尝试绕过锁屏。
