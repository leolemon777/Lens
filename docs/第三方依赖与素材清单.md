# Lens 第三方依赖与素材清单

状态：Public Beta 前持续审计。本文只记录实际进入源码仓库或发布 App 的内容，不把竞品调研材料视为可分发资产。

## 当前代码依赖

- Swift Package Manager 没有远程 package、二进制 target 或 Git submodule；`LensMac` 只依赖仓库内的 `LensCore`。
- App 使用 macOS 系统提供的 AppKit、SwiftUI、ScreenCaptureKit、AVFoundation、AVKit、Speech、Vision、ApplicationServices、Carbon、CoreGraphics、CoreImage、CoreMedia、CoreText、CoreVideo、ImageIO、UniformTypeIdentifiers、Combine 和 Foundation。
- 测试只额外使用系统 XCTest；测试视频、音频和位图均在运行时合成，不从第三方素材包复制。
- 界面当前使用系统 SF Symbols 名称，不把符号文件复制进仓库或发布包；只用于 Apple 平台原生界面。

## 当前发布资产

- 仓库只跟踪一项二进制品牌资产：项目原创生成的 `Assets/AppIcon.png`。其来源、提示词、规格与固定 SHA-256 见 `docs/品牌资产说明.md`；构建时生成的 `AppIcon.icns` 位于被忽略的 `Build/`，不进入源码仓库。
- 除上述 App 图标外，仓库没有跟踪图片、视频、音频、字体、模型、证书、崩溃报告、`.lens` 项目包或预构建二进制。
- 当前 App 没有品牌字体、模板媒体、示例项目或模型权重。加入这些资产前，必须在本清单补充来源、作者、许可证、修改情况和再分发依据。
- 本地竞品体验视频和真实捕获素材受 `.gitignore` 排除，只能用于本机测试，不进入 Git、DMG 或公开下载附件。
- DMG、App zip 和 dSYM 是本地生成物并位于被忽略的 `Build/`；它们不是源码仓库内容。

## 自动审计

执行：

```bash
bash Scripts/audit-public-source.sh
```

脚本检查必需公开文档与发布说明生成器、Git submodule/符号链接、单文件大小、非文本文件、媒体/项目/崩溃/发布/签名文件扩展名，以及常见私钥和访问令牌格式。唯一允许的 PNG 是固定为 1024×1024、不透明且 SHA-256 与审计记录一致的 App 图标。脚本只证明“当前被 Git 跟踪的源码适合进入公开仓库”，不能替代人工资产许可审查、依赖许可证审查或秘密扫描服务。

## 公开发布前仍需决定

- 选择 Lens 自身的开源许可证并添加根目录 `LICENSE`；在此之前源码可见不等于已授权开源。
- 为正式应用图标和后续模板/示例项目建立可追溯来源；没有明确授权的竞品截图、录屏、Logo、音乐、字体或模型不得进入仓库与安装包。
- 每次新增 Swift package、Rust crate、Windows NuGet/WinUI 组件、模型或云 SDK 时，同步记录版本、许可证、上游地址、用途和是否随包分发。
