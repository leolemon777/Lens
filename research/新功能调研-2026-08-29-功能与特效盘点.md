# 新功能调研：市面录屏/截屏软件的功能与特效盘点（2026-08-29）

范围与定位：本文是 [截图录屏竞品与开源项目调研-2026-08-09](截图录屏竞品与开源项目调研-2026-08-09.md)
与 [Lens-竞品能力吸收矩阵](../docs/Lens-竞品能力吸收矩阵.md) 的**增量补集**——那两份已覆盖
市场结构、GitHub 项目、口碑信号与 M3–M7 吸收规划；本文只盘点其未展开的**具体功能与特效**，
尤其是 2026 年的 AI 能力新趋势，最后对照 Lens 现有架构给出差距与优先级建议。

## 一、AI 内容增强：从"录下来"到"剪干净"

### 1.1 静默与口误一键清除（Tella / Loom / Gling / TimeBolt）

- [Tella](https://www.tella.com/features/ai-editing)：编辑器里一个 **Trim 按钮**同时移除全部
  静默段和填充词（"um/uh"），并可**直接在转写文本上做修剪**——删字即删片段；
- [Loom AI](https://www.loom.com/ai)（Business+ 档）：filler word + silence removal、
  自动标题（免费档全量）、自动摘要/章节/任务提取（[官方功能表](https://support.atlassian.com/loom/docs/loom-ai-features/)）；
- 社区反馈（[Descript 用户组](https://www.facebook.com/groups/descriptusers/posts/1294431016176166/)）：
  全删口误会显得"跳"，**选择性移除**体验更好——可审阅的删除建议是正确形态。

**对 Lens 的意义**：教程/演示录屏的第一刚需。Lens 已具备全部地基——分段时间线、
设备端转写、`NarrationActivityAnalyzer`（语音活动区间检测已是 ducking 的一部分）、
非破坏 `VideoEditTimeline`。"检测静默段 → 生成可逐条接受/拒绝的剪除建议"是纯增量。

### 1.2 AI 配音与多语言（Arcade / Supademo / Kite 方向）

- [Arcade](https://www.arcade.software/) 免费档即含**合成语音配音**；热点样式、平移缩放
  效果叠加在演示上（[评测](https://saltfish.ai/blog/arcade-review)）；
- [Supademo](https://supademo.com/) 2026-06 上线 **AI Demo Agent（含语音克隆）**，
  并支持自动多语言翻译配音（[社区对比](https://www.reddit.com/r/ProductMarketing/comments/16piggb/interactive_demo_platform_comparison/)）；
- Snagit/Camtasia 的 "Screen Intelligence" 工作流把截图素材送进在线剪辑（[报道](https://www.videomaker.com/news/techsmith-boosts-snagit-and-camtasia-with-ai-and-screentelligence-powered-workflows/)）。

**对 Lens 的意义**：Lens 已有转写时间轴与字幕轨——TTS 用系统语音起步（零成本），
`transcript.json` 的 cue 结构天然可以换成配音轨；多语言字幕翻译是转写的自然延伸。

## 二、交互式演示/SOP 文档品类（既有调研未覆盖的整条品类）

核心机制：**录制点击过程 → 自动生成带编号截图的步骤文档或可点击演示**。

| 产品 | 模式 | 特色 | 价格信号 |
|---|---|---|---|
| [Tango](https://www.tango.ai/) | SOP 文档 | 录制即出带标注步骤指南，面向 IT/运营 | $15/用户/月，3 席起 |
| [Scribe](https://scribe.com/tools/sop-generator) | SOP 文档 | 自动捕获点击成文档，免费档强 | $13/席/月，5 席起 |
| [Supademo](https://supademo.com/) | 可点击演示 | HTML 捕获、语音克隆、多语言 | 见官网 |
| [Arcade](https://www.arcade.software/) | 可点击演示 | 免费档含摄像头+AI 配音 | 免费起步 |
| Storylane / Navattic / Walnut | 营销演示 | 嵌入官网、线索捕获 | 企业向 |

参考对比：[2026 交互演示软件横评](https://www.stepshots.com/blog/best-interactive-demo-software)、
[HappySupport: Scribe vs Tango](https://www.happysupport.ai/en/blog/scribe-vs-tango)。

[Snagit 2026](https://www.techsmith.com/snagit/whats-new/) 的 **Step Capture** 是桌面端同款：
点击过程自动抓图 → 编号视觉指南，且**步骤中的光标可移动/删除/缩放**。

**对 Lens 的意义**：这是 Lens 架构的"免费午餐"——点击事件轨 + 每步截图 + OCR +
章节生成都已存在，缺的只是"把点击序列组装成步骤文档（Markdown/HTML 导出）"这一层。
本地、无账号、开放格式地做 Tango/Scribe 的核心场景，差异化极清晰。

## 三、视觉特效与画幅

- **多画幅重构**：[Screen Studio](https://screen.studio/) 支持 9:16/1:1/4:3/3:4/4:5，
  切换画幅时**运镜动画自动重算**（[竖屏教程](https://tight.studio/blog/how-to-make-a-vertical-video-with-camera-in-screen-studio/)）；
- **动态摄像头动画**：开场全屏摄像头、视频中段隐藏摄像头（[changelog](https://preview.screen.studio/changelog)）；
- **设备框**：Mac/iPhone 外框 + 免费生成器（Screenhance、[Mockup Frame](https://apps.apple.com/sa/app/mockup-frame-device-mockups/id6468902504)）；
- **代码截图美化**（[ray.so](https://www.ray.so/) / [Carbon](https://carbon.now.sh/)）：
  语法高亮、主题、渐变背景、暗/亮窗口——"粘贴代码出美图"已是开发者刚需；
- [CleanShot X](https://cleanshot.com/changelog) 近期值得注意的细节：
  **水平方向长截图**（横向滚动）、截图智能摆放（before/after 对齐）、
  **光标自动缩放到与图中文字匹配**、10 组渐变壁纸、录制中**自动隐藏系统通知**、
  简单修剪工具、共享媒体的**查看/评论推送通知**；
- [Snagit 2026](https://support.techsmith.com/hc/en-us/articles/42674936732685-Snagit-Windows-2026-Version-History)：
  光标高亮底色、Quick Image Annotation、低对比度 OCR 增强。

## 四、摄像头 AI

- **背景移除/虚拟背景**：Chrome 扩展生态已把"AI 背景 + 录屏"打包
  （[AI Webcam Effects](https://chromewebstore.google.com/detail/ai-webcam-effects-+-recor/iedbphhbpflhgpihkcceocomcdnemcbj)）；
- **眼神接触校正**（VEED / Kapwing / BIGVU / ngram）：后期把偏离镜头的目光修正为直视；
- **平台商品化**：macOS 26.2 的 **Edge Light**（原生摄像头环形补光，[Macworld 追踪](https://www.macworld.com/article/2644146/macos-26-features-latest-update-release-date-beta.html)）。

**对 Lens 的意义**：背景移除用 Apple Vision 人像分割**本地可做**、与现有
`PresenterCameraRenderer` 圆形/圆角裁切同一层；眼神接触涉及人脸注视重定向，建议 1.x 后评估。

## 五、截图智能与隐私

- **语义搜索成为新细分赛道**：移动端（Screenshot Search & Chat、SnapStash AI 的
  "和截图库对话"）与桌面端（[Pizazoo](https://mark-it.co/screenshot-organizer-app) 用
  Apple Vision 全离线）都在做"自然语言找截图"；2026 年综述明确指出
  **CleanShot X 没有语义搜索**——这是在位者的空位；
- **Smart Redact**：Snagit 识别 **9 类敏感信息**（邮寄地址等 PII），黑条/模糊/像素化，
  "Spot Redact" 自动检测一键遮挡（[Videomaker 报道](https://www.videomaker.com/news/techsmith-boosts-snagit-and-camtasia-with-ai-and-screentelligence-powered-workflows/)）；
- Lens 的 `LocalLensOrganizer` 已识别 6 类（凭据/邮箱/身份证/卡号/电话 + 脱敏），
  差距在"命中 → 一键生成遮挡标注"的闭环。

## 六、分享与观看（矩阵 M7 的具体功能形态）

- **查看/评论推送通知**（CleanShot 4.8.4）：分享后对方首次查看/评论时推送；
- **观看分析**：谁看了、看了多久、完成率（[Loom vs Vidyard](https://speakwiseapp.com/blog/loom-vs-vidyard)）；
- **CTA / 邮件门 / 品牌页**：[Vidyard](https://www.vidyard.com/blog/video-call-to-action/)
  时间戳 CTA + 邮件门、[Wistia](https://wistia.com/explore/video-marketing) Turnstile
  铅捕、[Send.co](https://www.send.co/blog/how-to-capture-emails-on-shared-loom-videos)
  给 Loom 式分享加观看门。

## 七、平台商品化压力（需要知道但不必追随）

macOS Tahoe 26：菜单栏原生录制控件、截图工具新增视频录制能力、Liquid Glass 重设计
（[Apple World Today](https://appleworld.today/2026/06/how-to-take-screenshots-in-macos-tahoe/)）；
同时存在原生工具破坏立体声捕获、悬浮缩略图 bug 等问题
（[Apple 讨论](https://discussions.apple.com/thread/256163770)、[Reddit](https://www.reddit.com/r/MacOS/comments/1rdcha0/since_macos26_a_lot_of_times_the_screenshot/)）。
结论：基础"能录"继续贬值，Lens 的差异化应继续压在**成片质量、素材库智能、开放格式**上。

## 八、对照 Lens 的差距与建议优先级

> 判断依据：用户价值 × Lens 现有架构的"免费程度"（事件轨/编辑计划/OCR/insights/开放格式）
> × 与既有 Beta P0/P1 规划的契合度。

### 建议尽快做（架构基本就绪，价值最高）

| 功能 | 竞品参照 | Lens 形态 | 就绪度 |
|---|---|---|---|
| 静默段清除建议（可逐条接受） | Tella Trim、Loom AI | RMS/语音活动检测找静默 → 时间线剪除建议，非破坏、可拒绝 | 转写+分析器+时间线全在 |
| 一键步骤文档 | Tango/Scribe/Snagit Step Capture | 点击序列+每步截图+OCR → 编号 Markdown/HTML 导出 | 点击轨+OCR+章节全在 |
| 敏感信息→遮挡建议闭环 | Snagit Smart Redact(9 类) | insights 命中 → 生成 blur/pixelate 标注建议（截图+视频统一），审阅后生效 | 检测已有，缺建议层 |
| 击键/点击胶囊显示 | PixPin 键鼠显示、Snagit 光标高亮 | keyboard/pointer 事件轨渲染成屏幕胶囊（隐私过滤已内置） | 事件轨全在，缺渲染层 |

### 第二梯队（成片上限）

| 功能 | 竞品参照 | 说明 |
|---|---|---|
| 多画幅重构 9:16/1:1 + 设备框 | Screen Studio | 画幅切换自动重算运镜；渲染端画布/运镜已分离 |
| 语义搜索/库问答 | Pizazoo、SnapStash 趋势 | 本地 embedding + 现有统一索引；CleanShot 明确缺此能力 |
| TTS 配音（系统语音起步） | Arcade 合成配音 | transcript cue → 配音轨；后续可接语音克隆 |
| 代码截图美化 | ray.so/Carbon | OCR 文本 → 代码块识别 → 主题化重渲染导出 |
| 摄像头背景移除 | 各家 | Apple Vision 人像分割，本地；挂进 PresenterCameraRenderer |

### 后置（依赖分享平台或高复杂度）

- 停止即链接 + 查看/评论推送（矩阵 M7，需 BYO 云）；
- 观看分析 / CTA / 邮件门 / 品牌页（分享平台层，随 M7）；
- 眼神接触校正（人脸注视重定向，成本高收益存疑）；
- 可点击交互演示导出（Arcade/Supademo 形态，HTML 播放器是独立工程）。
