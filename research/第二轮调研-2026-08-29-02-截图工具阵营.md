## 1. CleanShot X（macOS，MTW）

**最新版**：4.8.10（2026-07-21）。（来源：https://cleanshot.com/changelog ）

**完整功能清单**（来源：https://cleanshot.com/features ）：
- **Quick Access Overlay（悬浮预览）**：截图/录屏后角落弹出小窗，可即时查看、标注、保存、复制、上传、拖拽到任意 App；支持滑动手势、多显示器、自动关闭策略、恢复刚关闭的 overlay、临时隐藏、快捷动作。
- **截图历史（Capture History）**：最多保存 1 个月，可按捕获类型过滤、恢复、删除（4.7 起）。
- **标注编辑器**：裁剪（定比例+吸边）、箭头（4 种含曲线）、矩形/椭圆/直线、像素化（带随机化防还原）、模糊（安全模式）、聚光灯、序号（教程步骤）、铅笔（自动平滑）、荧光笔（4.7 起 Smart Highlighter 自动识别单词调整笔宽）、文字（7 种预设样式）、多图合并、可编辑 .cleanshot 工程格式。
- **Background 工具**：加背景、调边距/对齐/比例，**Auto Balance 自动平衡边距**，10 种背景+自定义，可存预设。
- **长截图/滚动截图**：**4.8（2025-05）新增水平滚动截图**；4.8 新增长截图多页打印、拼接改进。
- **OCR**：完全本机运行、自动检测语言（4.8）、Tahoe 上新增 10 种小语种（4.8.4，跟随系统 Vision 框架）。
- **贴图（Floating Screenshots/Pin）**：置顶、调大小透明度、方向键精确定位、Lock Mode 可穿透操作下层应用。
- **录制**：MP4/GIF、窗口/区域/全屏、录系统声音（无需驱动，4.6 新音频引擎）、麦克风、显示点击/按键/摄像头、自动勿扰、内置视频编辑器。
- **云链接分享（CleanShot Cloud）**：一键上传得链接，支持自毁、密码保护、标签、自定义域名与品牌、团队管理；**4.8.4 新增推送通知**。
- **其他**：All-In-One 单快捷键模式、窗口截图可后期换背景/去阴影/透明（4.8）、定时、冻结屏幕捕获动态对象、十字线+放大镜、WebP/HEIC、sRGB 转换、取色器（4.8）、URL Scheme、Raycast 集成。
- **2025–2026 确认项**：水平长截图（有）、Tahoe 全新界面（4.8.5）、推送通知、取色器、可编辑窗口截图。**语义搜索：没有**（历史仅支持按类型过滤，无搜索框）。

**体验闭环**：快捷键 → 捕获 → 角落 Quick Access 悬浮预览 → 直接复制/拖进聊天窗口/标注/上传得链接 → 历史可找回 → 需要参考就 Pin 在屏幕。用户证言（https://cleanshot.com/testimonials ）：Tyler Hall "一天用 50+ 次，值每一分钱"；Fabrizio Rinaldi "macOS 本来就有的功能被它做到 1000 倍好"。

**定价**（https://cleanshot.com/buy ）：买断 $35/1 Mac、$59/2 Mac、$139/5 Mac、$269/10 Mac，含 1 年更新，续费 $19/年；也可经 Setapp 订阅；学生 7 折。

**口碑要点**：
- HN："想付费就买 CleanShot……（非常）快乐的用户，这可能是最讲道德的软件授权"（https://news.ycombinator.com/item?id=31773863 ）
- V2EX：Black Friday 优惠帖（2025-11）、Tahoe 26.0 初期"无法标注"问题与解法帖（2025-07），官方在 4.8.3/4.8.5 快速跟进 Tahoe 兼容。

## 2. Shottr（macOS，独立开发者）

来源：https://shottr.cc/ （v1.9.1，安装包仅 2.3MB，原生 Apple Silicon）

**独有能力清单**：
- **测距/屏幕标尺**：方向键测垂直/水平尺寸，鼠标悬停两物体之间测间距，点击即把尺寸"烙印"在截图上；Retina 可切换逻辑/物理像素计量。
- **取色**：TAB 取光标下像素色；Shift+TAB 自动取文字 darkest 像素；C 键取选区平均色。
- **放大镜**：Z 键点击即放大，cmd+2 快速放大选区。
- **像素级选区**：方向键 1px/Shift 10px 微调、A 键智能选区自动贴合、⌘+点击自动选中纯色物体。
- **拼图（Combine）**：多次截图放同一画布；叠图半透明对比、生成两帧 before/after 动图。
- **马赛克/对象移除**：像素化遮挡、直接"删除"敏感物体（背景自动填补）；**Text mode 只抹文字不破坏背景**（作者称最自豪的功能之一）。
- **滚动截图**、**OCR + 二维码**（框选即复制）、渐变背景+阴影+圆角美化、贴图、指定文件夹归档（收据/票据场景）、Raycast/Alfred 集成。
- **没有的**：视频/GIF 录制、截图历史管理器、iCloud 上传都还在 roadmap（官网投票区可证）。

**为什么开发者喜欢**（HN 184 分 94 评论，https://news.ycombinator.com/item?id=31773863 ）：作者自述做 Shottr 是为了"探索像素"——放大看渲染质量、量尺寸、精确选区；评论区称赞滚动截图、图标移除+背景自动填充、轻量（"17ms 抓取、165ms 显示"）；免费模式被广泛好评。争议点：遥测（可退出），以及"像素化不等于安全脱敏（可被还原）"。

**定价**：可免费一直用（偶尔弹购买提示）；付费为"输入任意价格（$0 也可以）"激活；S3/图床上传需激活后才可用。

## 3. Xnapper（macOS/iOS/Web，独立开发者）

来源：https://xnapper.com/ 、https://xnapper.com/changelog 、https://xnapper.com/pricing

**自动美化细节**：
- **自动平衡边距（Automatic balance）**：一键让截图四周留白对称居中，"2 秒得到一张漂亮截图"。
- **自动背景色**：自动从截图内容提取/搭配合适背景，支持渐变与自定义背景图、壁纸。
- **敏感信息自动模糊（Automatic redact）**：一键识别并遮挡**邮箱、信用卡号、IP 地址、API key**（v1.15.5 起扩展；v1.18 起像素化遮挡可再编辑、缩放且每次缩放只记一步撤销）；Web 版可选透明或实色遮挡。
- **其他**：圆角+阴影自动随窗口截图套用、社媒尺寸/比例预设、输出压缩、截图历史、从文件/剪贴板打开、Presets 预设、拖我按钮、Share Extension。
- **OCR**：基于 macOS Vision、完全本机、选中即复制。

**录屏**：**没有录屏功能**（v1.18 changelog 里的 "Screen Recording permission recovery" 指截图所需的屏幕录制权限恢复引导，并非录屏）。

**2024–2026 版本线**：Xnapper Web（2024-09：iPhone/MacBook/Safari/iPad 设备外壳 mockup、标注、遮挡；2024-12 云存储与链接分享）；macOS v1.18（2026-08-25）标注样式自定义增强。

**定价**：免费带水印；买断去水印 Basic $29.99（促销 $15）/ Personal $54.99 / Standard $79.99 / Team $5/设备/月；买断永久可用+1 年更新；30 天退款。

**口碑**：官网自述 4.9 分、"服务 4,000 名创作者每日美化截图"；Xnapper Studio Web 版 Show HN 41 分。

## 4. Snagit 2026（TechSmith，已并入 Camtasia 套件）

来源：https://www.techsmith.com/screen-capture.html 、https://www.techsmith.com/snagit/features/ 、https://www.techsmith.com/camtasia/whats-new/

**核心功能**：
- **AI Step Capture（步骤捕获）**：边点击操作边自动生成带截图的分步指南，截图直接转文档。
- **Smart Redact（智能脱敏）**：AI 一键识别并遮挡截图中的敏感信息。
- **滚动截图**、**Simplify**（AI 把复杂截图简化成示意图）、**Smart Move**（AI 识别截图里的 UI 元素并可拖动重排）、**OCR**（截图内文字可编辑/复制/删除）、AI 背景降噪。
- 标注体系：语音气泡、图章/模板库（Snagit Assets）、截图转网站页、视频转 GIF。

**2026 年与 Camtasia 的深度整合**：
- 2026.2（2026-08）：**Step Capture to Video** —— Snagit 步骤截图一键进 Camtasia 时间线，每步变独立片段并自动加转场与下三分之一标题，一次操作同时产出图文指南+视频教程。
- 2026.1（2026-04）：**Edit in Snagit from Timeline** —— 时间线上的旧截图可直接拉回 Snagit 改文字/换图标，自动替换回时间线。

**企业部署**：官方主打 "Camtasia for Enterprise"，首页宣称"被 100% 的财富 500 强使用"（官方口径）；订阅制保证团队始终最新版、账号制授权便于 IT 管理。

**定价**：个人订阅 $39/用户/年；所有 Camtasia 套餐均含 Snagit。

## 5. 国产阵营

### 5.1 PixPin（深圳深度图景，Windows + macOS）
来源：https://pixpinapp.com/ 、V2EX 3.0 发布帖（2026-04-14，25205 浏览/950 回复，https://www.v2ex.com/t/1205693 ）

## 6. macOS 原生（截图工具栏 / Sequoia / Tahoe）

来源：https://support.apple.com/en-us/HT201361 （2026-03 更新）

## 7. Windows 侧（简要）

### 7.1 ShareX（开源免费）
来源：https://getsharex.com/

- **捕获**：全屏/活动窗口/显示器/区域/上次区域/自定义区域/屏幕录制（含 GIF）/滚动截图/自动捕获。
- **捕获后动作链（After capture tasks）——ShareX 的灵魂**：快速任务菜单、美化图像、图像编辑器、复制到剪贴板、**钉到屏幕**、打印、保存、执行外部动作、复制文件/路径、图像分析、扫二维码、OCR、**上传到图床（官方提供 Amazon S3 / Google Cloud Storage / Cloudflare R2 指南）**、删除本地文件。可把"截图→OCR→上传→复制链接→删本地"编排成一键流。
- 独立页面还有背景移除、OCR、贴图（Pin to screen）。

### 7.2 Snipping Tool（Windows 11，AI 功能）
来源：Microsoft 支持文档、Windows Insider 博客、Windows Latest

## 8. 截图体验闭环做得最好的地方

| 闭环环节 | 最顺的 | 好在哪 |
|---|---|---|
| **截完即用** | **CleanShot X** | Quick Access Overlay 是唯一把"查看-标注-复制-保存-上传-拖走"全部收进角落小窗的设计，不打断心流 |
| **拖拽交付** | **CleanShot X / Xnapper** | CleanShot overlay 可拖进任意 App；Xnapper 的 "Drag Me"；PixPin 3.0 也学会了拖图入悬浮窗即贴图 |
| **找回历史** | **CleanShot X** | 1 个月捕获历史+按类型过滤+恢复；Snipaste 的"历史回放"是轻量替代 |
| **贴图** | **Snipaste（交互）/ PixPin（功能广度）** | Snipaste 定义了贴图交互（穿透/透明度/旋转/分组）；PixPin 做出 6 种贴图+分组+图上文字直接复制 |
| **OCR** | **CleanShot X（Mac）/ PixPin（中文+贴图内选字）/ Snipping Tool（Win，OCR+一键脱敏）** | CleanShot 完全离线+自动语言；PixPin 简繁中英日同识别；Snipping Tool 把 OCR 与脱敏合并成一步 |

**结论**：体验闭环整体完成度最高的是 **CleanShot X**；"截完即用"的另一种范式是 **Xnapper**（截完自动变漂亮，零操作直接发）；中文办公场景闭环王者是 **PixPin**（OCR+长截图+贴图+录制中标注，且免费）；开发者像素工作流是 **Shottr**。

## 9. 自动美化与智能功能盘点

| 能力 | 做到什么程度 / 谁有 |
|---|---|
| **自动美化（边距/背景）** | Xnapper：自动平衡边距+自动背景色，一键全自动，核心卖点；CleanShot X：Auto Balance 需手动进入；iShot/Shottr：圆角+阴影 |
| **敏感信息自动遮挡** | 第一梯队（AI 一键）：**Snagit Smart Redact**、**Xnapper Auto redact（邮箱/卡号/IP/API key）**、**Snipping Tool Quick redact（邮箱/电话）**；第二梯队（手动但讲究）：CleanShot 像素化"带随机化更安全"、Shottr Text mode 只抹字不破坏背景、PixPin/iShot 马赛克 |
| **OCR 智能整理** | 全员普及；最"智能"的是 Snagit——OCR 与 Smart Move（AI 识别 UI 元素可挪动）联动改图 |
| **截图转文档/教程** | **Snagit AI Step Capture 独有**；2026 年还能一键转成 Camtasia 视频 |
| **语义搜索** | **全员没有**。这是当前截图工具普遍空白点 |
| **设备外壳/排版美化** | Xnapper（iPhone/MacBook/Safari/iPad mockup）、iShot（带壳截图）、Snagit（模板+图章库） |
